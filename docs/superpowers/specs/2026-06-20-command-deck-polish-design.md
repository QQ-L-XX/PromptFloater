# Command Deck 视觉精修设计

## 目标

在不改变布局、快捷键和数据行为的前提下，提高 Command Deck 的跨平台一致性与操作反馈精度。

## 设计

- 静态与动态操作图标统一使用一套 14×14、圆角线帽、1.8px 描边的固定 SVG。图标模板不接收用户数据。
- 数字快捷键按真实操作显示为 `[1]`–`[9]`，不再使用容易被理解为组合键的 `⌘1`。
- 分类显示名称移除 Emoji、变体选择符和多余空白；持久化数据中的原始分类名称保持不变。
- 复制成功后，当前条目操作区短暂显示青柠色 `COPIED ✓`，持续 900ms；保留原有 Toast 作为辅助反馈。

## 验收标准

- 标题栏、搜索、条目操作和工具菜单不再依赖字符图标。
- Windows 与 macOS 显示相同的 SVG 图标轮廓。
- 分类数据不被修改，但界面不显示分类 Emoji。
- 数字提示与实际单键操作一致。
- 复制反馈只出现在被复制的条目，动画结束后恢复原操作区。
- 现有安全渲染、保存和键盘测试全部通过。
