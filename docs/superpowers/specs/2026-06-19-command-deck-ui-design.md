# PromptFloater Command Deck UI 设计

## 目标

将 PromptFloater 从装饰感较强的深色悬浮卡片升级为键盘优先的“Command Deck”工具界面。保持窗口尺寸、数据格式、Python 服务、贴边能力和现有业务功能不变，提高信息密度、扫描速度与快捷操作效率。

## 视觉方向

采用用户确认的 B2“平衡密度”方案：

- 纯黑与中性灰构成主界面，减少玻璃、渐变和装饰性光效。
- 荧光青柠作为唯一主强调色，用于选中分类、快捷键、收藏、复制成功和贴边球。
- 默认窗口维持约 400×560，目标是一屏清晰展示 6–8 条提示词。
- 字体组合以系统无衬线字体负责正文、等宽字体负责编号、状态和快捷键。
- 动画短促克制，持续时间约 120–220 ms，不使用大幅位移或弹跳。

## 信息架构

### 顶栏

左侧显示紧凑的 `PF` 标记与 `COMMAND DECK` 名称。右侧保留贴边、固定和退出按钮。按钮保持小尺寸，但必须提供可读的 `title` 与 `aria-label`。

### 命令搜索区

搜索框呈命令输入区形态，默认提示 `/ 搜索或输入快捷指令`。本轮只实现搜索，不引入命令语言。`/` 聚焦搜索，`Esc` 清空或退出输入状态。

### 分类栏

分类以编号标签展示，例如 `01 VIB CODING`、`02 CODE`。当前分类使用青柠色文字与下划线或细边框，不使用大面积填充。分类过多时保持横向滚动。

### 提示词列表

每条提示词采用两层结构：

1. 第一行：序号、从内容提取的短标题、快捷键提示和收藏状态。
2. 第二行：提示词内容的一行摘要。

当前选中项使用深灰底、青柠色左侧指示线和更清晰的文字。鼠标悬停与键盘选中共用同一视觉语言，但键盘选中优先。

### 状态栏

底部显示 `N NEW`、`E EDIT`、`F FAV` 等可用快捷键，右侧显示当前过滤结果与分类总数，例如 `6 / 14`。导入、导出和分类管理放入紧凑的 `···` 工具菜单，避免底部按钮拥挤。

### 弹窗

新建、编辑、分类管理和退出确认沿用现有流程，改为 Command Deck 的纯黑、细边框、紧凑表单风格。输入、保存和错误反馈逻辑不变。

## 交互状态

前端状态增加 `selectedItemId`，鼠标与键盘操作共享这一状态。

- 初次加载、搜索或切换分类后，自动选择第一条可见提示词。
- `ArrowUp`、`ArrowDown` 在可见列表中循环移动选择。
- 选择变化后调用 `scrollIntoView({block: "nearest"})` 保持条目可见。
- `Enter` 复制当前选择。
- 数字键 `1`–`9` 复制当前列表对应条目。
- `N` 打开新建弹窗。
- `E` 编辑当前选择。
- `F` 切换当前选择的收藏状态。
- `/` 聚焦搜索。
- `Esc` 按优先级关闭弹窗、清空搜索或移除输入焦点。

当焦点位于 `input`、`textarea`、`select` 或可编辑元素时，除 `Esc` 和现有的保存组合键外，不触发全局快捷键。

## 数据流与错误处理

本轮不修改后端数据 API、JSON Schema 或持久化目录。所有新增、编辑、删除、收藏和导入操作继续通过现有 `persist()` 等待后端确认；失败时保持旧状态并显示错误。

动态内容继续使用 `document.createElement`、`textContent`、`dataset` 与 `replaceChildren`，不得恢复用户数据拼接 `innerHTML`。视觉图标优先使用文本符号或固定 SVG，不在固定模板中插入用户数据。

## 文件调整

- `demo.html`：替换主题变量和布局样式，调整静态结构与无障碍标签。
- `renderer/app.js`：增加选择状态、键盘导航、工具菜单和新的安全渲染结构。
- `tests/test_renderer_security.py`：保留安全断言。
- `tests/test_command_deck_ui.py`：新增主题标记、选中状态、快捷键、焦点保护和状态栏回归检查。
- `README.md`：更新界面说明与快捷键列表。

## 验收标准

- 界面符合 B2 平衡密度和荧光青柠视觉方向。
- 一屏在默认高度下清晰展示约 6–8 条条目。
- 鼠标、方向键、Enter、数字键、N、E、F、/、Esc 均按设计工作。
- 输入与编辑时不会误触全局快捷键。
- 搜索和分类切换后选择状态有效且可见。
- 所有用户数据继续通过安全 DOM API 渲染。
- 现有数据保存、导入、导出、复制、贴边和弹窗流程不回退。
- 全部 Python 测试、JavaScript 语法检查和桌面启动烟测通过。
